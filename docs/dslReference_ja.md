# chabo-dsl Language Reference

## 概要

**chabo-dsl** は、式評価を中心とした軽量なスクリプト言語です。

主な特徴は以下のとおりです。

* 数値演算
* 文字列操作
* 比較演算
* 論理演算
* 三項演算子
* 変数
* グローバル変数
* 配列
* ハッシュ
* ユーザー定義関数
* 再帰呼び出し
* 組み込み関数
* Unicode変数名

---

## データ型

### 数値

整数および浮動小数点数を使用できます。

```text
123
3.14
-10
```

#### 例

```text
1 + 2 * 3
```

結果:

```text
7
```

### 文字列

文字列はシングルクォートまたはダブルクォートで囲みます。

```text
"hello"
'world'
```

#### 例

```text
"abc"
```

---

## 変数

変数は代入によって定義します。

```text
x = 10;
arr = [1, 2, 3];
has = {a: 1, b: 2};
```

### ローカル変数

通常の代入はローカル変数として扱われます。

```text
a = 10;
b = a + 5;
```

### グローバル変数

`:=` を使用すると、グローバル領域に変数を保存します。

```text
a := 10;
```

---

## 配列

配列は `[]` を使用して定義します。

```text
[1, 2, 3]
```

### 配列へのアクセス

```text
a[0]
```

内部的には次の形式に変換されます。

```text
array(a, 0)
```

---

## ハッシュ

ハッシュは `{}` を使用して定義します。

```text
{
    name: "john",
    age: 20
}
```

### ハッシュへのアクセス

```text
user{name}
```

内部的には次の形式に変換されます。

```text
hash(user, name)
```

# 演算子

演算子には優先順位があります。

**優先順位の値が小さいほど弱い演算子です。**

## 比較演算子

以下の比較演算子を使用できます。

| 演算子  | 意味      |
| ---- | ------- |
| `!=` | 等しくない   |
| `<`  | 小さい     |
| `<=` | 小さいか等しい |
| `>`  | 大きい     |
| `>=` | 大きいか等しい |

### 自動型判定比較

比較時には `looks_like_number()` を使用して、数値か文字列かを自動判定します。

数値の場合:

```text
10 < 20
```

文字列の場合は、Perlの文字列比較演算子に相当する以下の比較を使用します。

| 比較      | 演算子  |
| ------- | ---- |
| 小さい     | `lt` |
| 大きい     | `gt` |
| 小さいか等しい | `le` |
| 大きいか等しい | `ge` |
| 等しい     | `eq` |
| 等しくない   | `ne` |

# ユーザー定義関数

## 関数の定義

以下の構文でユーザー定義関数を定義できます。

```text
add(a, b) = a + b
```

## 関数の呼び出し

```text
add(1, 2)
```

結果:

```text
3
```

---

# 関数呼び出し

関数は次の構文で呼び出します。

```text
func(arg1, arg2)
```

例:

```text
sqrt(9)
```

---

# 制御構文

## `return`

ユーザー定義関数から抜けます。

```text
return(expr)
```

例:

```text
fact(n) =
    n <= 1
    ? 1
    : n * fact(n - 1)

return(fact(5))
```

---

## `continue`

ユーザー定義関数の先頭に戻ります。

```text
continue()
```

---

# 再帰

ユーザー定義関数は再帰的に呼び出すことができます。

例:

```text
fact(n) =
    n <= 1
    ? 1
    : n * fact(n - 1)
```

この例では `fact()` が自身を呼び出しています。

## 文字列関数

### `uc`

```text
uc(text)
```

文字列を大文字化します。

### `lc`

```text
lc(text)
```

文字列を小文字化します。

### `length`

```text
length(x)
```

文字列または配列の長さを返します。

### `substr`

```text
substr(text, start, length)
```

文字列の一部を取得します。

### `split`

```text
split(regex, text)
```

正規表現を使用して文字列を分割します。

戻り値:

```text
配列
```

### `join`

```text
join(sep, array)
```

配列の要素を指定した区切り文字で連結します。

例:

```text
join(",", ["a", "b", "c"])
```

結果:

```text
"a,b,c"
```

### `match`

```text
match(regex, text)
```

正規表現にマッチした文字列の一覧を返します。

戻り値:

```text
配列
```

### `replace`

```text
replace(regex, replacement, text)
```

正規表現に一致した部分を置換します。

例:

```text
replace("a", "X", "abc")
```

結果:

```text
Xbc
```

# `map`

`map` は配列の各要素に式を適用し、その結果を配列として返します。

### 構文

```text
map(expr, array)
```

### 特殊変数

`$_` は、現在処理している配列要素を保持します。

### 例

```text
map($_ * 2, [1, 2, 3])
```

結果:

```text
[2, 4, 6]
```

# 実行制限

chabo-dsl には、無限再帰や長時間実行を防ぐための実行制限があります。

## 再帰制限

再帰呼び出しが1000回を超えると、以下の例外が発生します。

```text
stack over!
```

## 実行タイムアウト

実行時間が5秒を超えると、`AST::Timeout` 例外が発生します。

# 変数名

変数名はUnicodeに対応しています。

変数名には、Unicodeの文字・数字・アンダースコアを使用できます。

想定される形式:

```regex
[\p{L}_][\p{L}\p{N}_]*
```

## 有効な変数名

```text
foo
_bar
数量
売上2025
```
